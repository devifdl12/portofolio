# Website Portofolio Pribadi - Desainer Grafis

Repositori ini berisi kode sumber untuk website portofolio profesional milik **Devi Nurul Fadhila**, yang menampilkan karya dan pengalaman di bidang desain grafis.

## 📌 Topik yang Dibahas
- Showcase Proyek Desain Grafis (ID Card, Desain UMKM, Desain Feeds Instagram)
- Informasi Profil & Pengalaman Organisasi/Kerja
- Formulir Kontak Interaktif

## 🚀 Cara Menjalankan Secara Lokal
1. Download atau *clone* repositori ini.
2. Buka folder proyek di VS Code.
3. Jalankan menggunakan ekstensi **Live Server** pada file `index.html`.

## 🛠️ Tech Stack & Resources
- HTML5, CSS3, JavaScript (Vanilla)
- Google Fonts & Font Awesome
- Aset gambar karya pribadi desainer grafis
